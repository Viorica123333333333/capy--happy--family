# Capy-Happy-Family

A full-stack family life-management platform designed to help families organize tasks, finances, goals, plans, and everyday life in one shared digital space.

## Project Status

In active development.

## Planned Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Node.js
- Express
- Prisma
- MySQL
- Vitest
- Playwright
